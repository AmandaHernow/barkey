About the project

A camera scanner where you type

BarKey is a free Android Input Method Editor (IME). After you enable it in Android settings and select it from the keyboard picker, focus a text field and point the rear camera at a barcode. BarKey decodes each frame on the device and inserts the result at the active cursor through Android’s input-method connection. It does not use the clipboard or keep a scan history.

Fast mode is the default for ordinary printed codes. Accurate mode applies additional processing for difficult, angled, damaged, or inverted labels and can take longer. Tap the preview to request focus and exposure at that point; a torch control appears when the camera supports flash.

Features

Scanning and editing tools

  • QR Code, Micro QR, rMQR, Data Matrix, Aztec, PDF417, MicroPDF417 and MaxiCode.
  • UPC-A, UPC-E, EAN-8, EAN-13, Code 39, Code 93, Code 128, ITF and Codabar.
  • GS1 DataBar (RSS-14) and GS1 DataBar Expanded (RSS Expanded), including Omni, Stacked, Stacked Omni, Limited and Expanded Stacked variants.
  • One-level guarded Undo, repeating Backspace, Space, Left, Right, Tab and Enter controls.
  • Docked, resizable keyboard with portrait and landscape layouts and light and dark appearance.

Supported formats are configured in the app. Camera behavior and editor actions can vary by device and the application containing the text field.

The thinking behind it

Useful software should stay accessible

I create free software because useful tools should not require an account, an unnecessary subscription, or a stream of advertisements. In my own applications, I oppose unnecessary subscriptions, advertising, tracking, and paywalls. BarKey has no paid features; an optional donation does not unlock anything.

Privacy by design

Local scanning, clear boundaries

BarKey’s source manifest removes Internet and network-state permissions. Camera frames and barcode decoding stay on the device. The app has no accounts, analytics, advertisements, tracking, or permanent scan history. Temporary scan and Undo data is held in memory only as needed by the active input session.

Open Source & Credits

BarKey — developed by Amanda Hernow — is licensed under the Apache License 2.0. Barcode decoding runs locally with ZXing-C++ Android 3.1.1 as the primary decoder and ZXing Core 3.5.4 as a Java fallback. Both projects use Apache License 2.0.

AndroidX CameraX provides camera capture and preview; AndroidX Core and Lifecycle provide Android application support. Google Guava 33.7.2-android is a CameraX support dependency pinned by BarKey. These libraries use Apache License 2.0; CameraX camera-core artifact metadata also declares BSD-3-Clause material.
